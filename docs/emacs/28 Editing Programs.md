This chapter describes Emacs features for facilitating editing programs. Some of the things these features can do are:

- Find or move over top-level definitions (see [Top-Level Definitions, or Defuns](/docs/emacs/Defuns)).
- Apply the usual indentation conventions of the language (see [Indentation for Programs](/docs/emacs/Program-Indent)).
- Balance parentheses (see [Commands for Editing with Parentheses](/docs/emacs/Parentheses)).
- Insert, kill or align comments (see [Manipulating Comments](/docs/emacs/Comments)).
- Highlight program syntax (see [Font Lock mode](/docs/emacs/Font-Lock)).
