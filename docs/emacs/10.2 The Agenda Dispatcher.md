The views are created through a dispatcher, accessible with `M-x org-agenda`, or, better, bound to a global key (see [Activation](/docs/emacs/Activation)).
It displays a menu from which an additional letter is required to
execute a command.  The dispatcher offers the following default
commands:


### `a`

Create the calendar-like agenda (see [The Weekly/Daily Agenda](/docs/emacs/Built_002din-Agenda-Views)).

### `t`, `T`

Create a list of all TODO items (see [The Global TODO List](/docs/emacs/Global-TODO-List)).

### `m`, `M`

Create a list of headlines matching a given expression (see
[Matching Tags and Properties](/docs/emacs/Matching-Tags-and-Properties)).

### `s`

Create a list of entries selected by a boolean expression of
keywords and/or regular expressions that must or must not occur in
the entry.
